Drop a real ocean-caustics loop here named exactly:

    ocean-caustics.gif

and it will automatically be used as the background instead of the
built-in CSS animation. Free, legit places to grab one:

  - https://www.pexels.com/search/videos/ocean%20caustics/
  - https://pixabay.com/videos/search/caustics/

(Both offer free-to-use video loops. If you download an mp4 instead of
a gif, see the "Using a video instead of a gif" note in the main
README.md for the one-line swap.)
